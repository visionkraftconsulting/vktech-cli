Pipeline

One command, four steps

Point it at a file or a directory. It extracts the audio, transcribes it, and writes the files next to your media.

01 · EXTRACT

Pull the audio

ffmpeg extracts 16 kHz mono audio from any video or audio file.

02 · TRANSCRIBE

Speech to text

whisper.cpp runs a local model — accurate, offline, GPU-accelerated on Apple Silicon.

03 · WRITE

.txt & .srt

Clean transcript plus a fully timestamped subtitle file, named to match your media.

04 · COMBINE

One master doc

Optional — merge every transcript in a folder into one document, headed by filename.

FAQ

Questions

Does my audio get uploaded anywhere?

No. Transcription runs entirely on your own machine using whisper.cpp. Nothing is sent to any server — there's no API key and no per-minute cost. It works fully offline.

What formats can I transcribe?

Any common audio or video file — MP4, MOV, MKV, WEBM, AVI, M4V, MP3, WAV, M4A, AAC, FLAC, OGG, OPUS. Point it at a folder and it transcribes every media file inside.

How accurate is it, and can I make it more accurate?

The default small.en model is accurate for clear English speech. For tougher audio or technical terms, pass --model medium or --model large-v3. Models download once and are cached locally.

Can I get subtitles as well as plain text?

Yes — add --srt for a fully timestamped subtitle file alongside the .txt, or --srt-only for just subtitles. Use --combine to merge a folder's transcripts into one document.

What do I need installed?

ffmpeg and whisper-cpp on your PATH (brew install ffmpeg whisper-cpp on macOS). The vktech CLI handles the rest, including downloading the model on first use.
